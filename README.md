# 拾知 · 课程复习工作台

上传课程资料 → 定制题型 → 在线作答 → 自动评分与逐题解析。本地运行，连接自己的模型 API。

线上地址：[https://shizhi-course-quiz.onrender.com](https://shizhi-course-quiz.onrender.com)（Render 免费实例）。

## 启动

Windows 安装 Python 3.11 或以上，双击 **启动网站.cmd**。首次启动会在项目的 `.venv` 中安装 PDF 解析依赖，需要联网。随后在浏览器打开 [http://127.0.0.1:8767](http://127.0.0.1:8767)，使用期间保持启动窗口开启。

也可手动执行：

```powershell
cd D:\Python\course-quiz
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

若默认端口被占用，可使用 `server.py --port 8768`，并打开对应端口。

## 使用

1. 新建课程，上传 PDF、DOCX、PPTX、TXT 或 MD，可多选。也可粘贴笔记。点击资料名称检查提取文字，尤其是表格和公式。
2. 点击「API 设置」，填写 Base URL、模型 ID 和 API Key，测试连接后保存。支持兼容 `/chat/completions` 的模型服务；接口自动追加该路径，也接受完整路径。本机模型可使用 `http://127.0.0.1:1234/v1` 等本地接口。
3. 直接在对话框描述要求，例如「出十道题，五道计算、五道判断，重点考折现，难度高一点」。不需要调整计数器或难度按钮；模型理解题数、题型和难度，支持计算题、判断题和四选一单选题。
4. 生成后在线作答，作答草稿保存在当前浏览器。提交后得到百分制评分、参考答案、解析和资料原文引用。
5. 从「练习记录」继续未完成测验或回看解析，从「我的错题」查看未答对的题目，可单独重练错题。

不设固定题数上限。较多题目会自动分批生成，显示完成进度；点击「停止」后，会在当前模型请求返回后停止，并保留已完成题目。总耗时、调用费用和可完成数量取决于资料覆盖范围及模型服务限制。未指定题数时默认 10 题；题数矛盾或题型不支持时会提示澄清。刷新页面后可继续查看当前生成任务；关闭或重启本地服务会中断正在生成的任务。

右上角可切换中英文并记住选择，新生成题目默认采用所选语言，已有题目和原资料不翻译。星光按钮开关粒子、鼠标连线和卡片跟随光晕；系统启用「减少动态效果」时自动关闭。

## 数据与评分

- 课程、提取出的资料文字、测验和成绩保存在 `data/study.db`。关闭服务不会丢失，备份时先关闭服务再复制 `data`。原始上传文件不落盘。
- API Key 只在当前页面和生成任务处理的内存中使用，不写入浏览器持久存储、数据库或日志；任务完成后释放任务配置，刷新页面后需重填。浏览器记住接口地址、模型名、课程、需求文字、界面语言、动效偏好、任务 ID 和作答草稿。
- 生成时，所选课程全部资料会发送给所配置的模型服务商；测试连接只发简短测试消息。单个文件最大 15 MB、PDF 最多 400 页、每门课提取文字合计最多 18 万字符。超限明确报错，不会静默截断。实际可容纳资料量还取决于模型上下文限制；若服务商提示上下文过长，请减少资料。
- 判断题、选择题精确核对；计算题只评分一个最终数值，按题目给出的绝对误差核对，不计步骤分。所有题等分，空题计错。百分数按题干单位输入，例如 8% 填 8（也接受 8%）。支持科学计数法、正确分组的千位分隔符。
- 未提交时服务端不向浏览器发送答案和解析。首次提交保存结果，重复提交不会改分；可开启新的重练测验。
- 模型输出会校验题型数量、重复题干、答案格式、有限数值、误差范围和引用是否出现在资料原文中；不合格时不保存测验，显示具体错误。原文匹配不能证明模型推理正确，答案有疑问时请回到资料核对。
- 目前读取可提取文字的文件。扫描 PDF、图片、图中公式、Office 公式对象需要先 OCR 或粘贴文字；PPTX 提取幻灯片正文，DOCX 提取正文及表格文字，不处理讲者备注、批注或页眉页脚。
- 本地默认仅监听 `127.0.0.1`。线上模式按带签名的 HttpOnly Cookie 隔离浏览器工作区；不同浏览器无法读写彼此的课程、测验和成绩。当前没有跨设备账号同步。

## 上线部署

项目提供 `render.yaml`，在 Render 中选择本仓库，创建免费 Python Web Service。构建命令 `pip install -r requirements.txt`，启动命令 `python -B cloud_app.py`，健康检查 `/healthz`，区域 Singapore。

环境变量：

- `COURSE_QUIZ_CLOUD=1`
- `COURSE_QUIZ_SECRET`：由平台生成的至少 32 字符随机密钥，禁止提交到 Git。保留此值，轮换会使旧 Cookie 和旧备份失效。
- `PYTHON_VERSION=3.13.9`
- 平台自动提供 `PORT` 和 `RENDER_EXTERNAL_URL`；其他平台需设置 `COURSE_QUIZ_PUBLIC_ORIGIN=https://你的域名`。

免费实例的服务端磁盘会随重启或休眠重置。线上版会将资料、测验及已提交成绩作为加密快照自动备份到当前浏览器的 IndexedDB，服务器状态丢失后自动恢复。备份包含未交卷的加密题目，但浏览器不会得到解密密钥或明文参考答案。API Key 不进入备份。

请使用同一个浏览器并保留网站 Cookie 和浏览器存储；无痕窗口、清理网站数据、换设备、改域名或更换服务端密钥后无法自动恢复原工作区。正在生成而尚未完成的任务在服务器重启后需重新发起。API 设置中线上版只允许公网 HTTPS 接口，不能访问你电脑上的本机模型。

免费实例空闲后会休眠，首次重新访问可能需要约一分钟。上述行为以 [Render 免费实例说明](https://render.com/docs/free) 为准。

线上使用 Waitress，限制 HTTP 连接、请求体大小、API 请求速率和上传解析并发；这些限制不限制一套练习的总题数。模型 HTTPS 连接在实际连接时解析域名并固定到校验过的公网 IP，禁用代理环境变量和重定向，防止通过模型地址访问云端内网。当前仍是个人使用版本，没有账号体系、WAF、独立文件扫描沙箱或完整渗透测试，不能据此承诺不会被攻击。

## 检查

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
node --check static/workspace.js
node --check static/effects.js
```

自动测试使用临时数据库，不修改正式学习记录。真实服务商连接、生成质量和延迟需要填写自己的 API Key 后验证。

接口依据：[DeepSeek 官方调用说明](https://api-docs.deepseek.com/)、[Chat Completions API](https://developers.openai.com/api/reference/resources/chat)。
